Case study

Natural Language Processing

DreamBank Enrichment & Generation

Worked with approximately 21,000 DreamBank reports, enriching them with emotion, topic and demographic metadata before comparing four Qwen3-1.7B-Base configurations.

01 / RESEARCH QUESTION

Research question

How do fine-tuning and enriched metadata affect language-model performance across four Qwen3-1.7B-Base configurations trained on DreamBank reports?

02 / DATA

Data

The project used approximately 21,000 DreamBank reports. The reports were enriched with emotion, topic and demographic metadata.

03 / TECHNICAL APPROACH

Technical approach

A RoBERTa-based model classified emotions, while BERTopic identified 25 topics. Four Qwen3-1.7B-Base configurations were compared, using QLoRA for parameter-efficient fine-tuning.

04 / MAIN RESULTS

Main results

Fine-tuning reduced token-level negative log-likelihood and perplexity. Adding metadata produced limited additional improvement.

05 / TECHNOLOGIES

Technologies

  • Python
  • Qwen3
  • QLoRA
  • Hugging Face
  • RoBERTa
  • BERTopic
