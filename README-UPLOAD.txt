HOW TO PUBLISH THIS PORTFOLIO ON GITHUB PAGES

1. Create a public GitHub repository named exactly: 1fiocco.github.io
2. Open the repository and choose Add file > Upload files.
3. Upload ALL files from this folder (not the folder itself).
4. Commit the files to the main branch.
5. Open Settings > Pages and select "Deploy from a branch".
6. Select branch "main" and folder "/ (root)", then save.

Your website will appear at:
https://1fiocco.github.io

The package contains separate Home, About, Projects and Contact pages.
To update the site later, edit the relevant HTML file or styles.css and commit the changes.
