# Riccardo Pugliese

[Live website](https://1fiocco.github.io/)

A lightweight personal website presenting Riccardo Pugliese's background in data science, data management, databases, data engineering and machine learning.

## Site structure

- **Home** — profile, availability and featured work
- **About** — education, international experience, technical toolkit and academic record
- **Projects** — ten academic and applied data projects
- **Contact** — contact links and internship availability
- **Case studies** — four detailed pages covering Home Credit Relational Database, DreamBank Enrichment & Generation, Bayesian Item Response Theory, and Unsupervised Book Clustering

## Technologies

The site is built with static HTML and CSS, without JavaScript frameworks or external dependencies.

## Downloadable assets

- `riccardo-pugliese-cv.pdf` — curriculum vitae
- `riccardo-pugliese-master-official-academic-record-redacted.pdf` — privacy-protected Sapienza MSc academic record
- `riccardo-pugliese-bachelor-official-transcript-redacted.pdf` — privacy-protected Roma Tre BSc transcript

## Preview locally

From the repository root, run:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000/` in a browser.
