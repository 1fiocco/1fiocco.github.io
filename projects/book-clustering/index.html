Case study

Data Pipeline · Unsupervised Learning

Unsupervised Book Clustering

Parsed 1,934 book HTML pages, created a Parquet dataset and transformed the collection into TF-IDF features, NMF topics and KMeans clusters.

01 / OBJECTIVE

Objective

Transform 1,934 book HTML pages into a structured dataset, then organise the collection through topic modelling and unsupervised clustering.

02 / DATA

Data

The source collection contained 1,934 book HTML pages. Parsing those pages produced a structured dataset stored in Parquet format.

03 / TECHNICAL APPROACH

Technical approach

The structured text was represented with 43,918 TF-IDF features. NMF learned 20 topics, and KMeans grouped the books into 15 clusters.

04 / MAIN RESULTS

Main results

The project created a Parquet dataset from 1,934 parsed pages, generated 43,918 TF-IDF features, learned 20 NMF topics and grouped the books into 15 KMeans clusters.

05 / TECHNOLOGIES

Technologies

  • HTML parsing
  • Parquet
  • TF-IDF
  • NMF
  • KMeans
