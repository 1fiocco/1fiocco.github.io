Case study

Data Engineering

Home Credit Relational Database

Built a relational PostgreSQL database from eight Home Credit source files, with a unified parent table, a chunked loader and analytical SQL.

01 / PROBLEM

Problem

How can eight Home Credit source files be organised as a relational PostgreSQL database that supports analytical SQL and query-performance analysis?

02 / DATA

Data

The database was built from eight Home Credit source files. A unified parent table connected the source structure.

03 / TECHNICAL APPROACH

Technical approach

Primary- and foreign-key relationships defined the relational structure. A chunked loader built with Python, PyArrow and SQLAlchemy handled data loading into PostgreSQL.

04 / MAIN RESULTS

Main results

The project produced ten analytical SQL queries. Query performance was analysed with indexes and EXPLAIN (ANALYZE, BUFFERS). The work focused on database design and SQL analysis rather than predictive modelling.

Technologies
